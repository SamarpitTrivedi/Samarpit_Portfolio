Power BI Analytics

Fraud Detection

An interactive fraud monitoring project built in Power BI to surface anomalous transaction patterns, risky time windows, and location-driven fraud trends.

View GitHub Back to Projects
Dataset Credit card transaction records with fraud labels and location context.
Tools Power Query, DAX, star-schema modeling, interactive BI reporting.
Goal Detect fraud early and give stakeholders a clearer risk-monitoring interface.

Concept

Fraud analysis built around explainability and action.

The project combines transaction preparation, feature engineering, and Power BI storytelling to help teams identify suspicious activity across amount, time, category, and geography.

Approach

Move from basic spotting to repeatable pattern analysis.

The analysis began with peak fraud timing and regional patterns, then expanded into category and amount-based risk analysis using DAX-driven views and layered filters.

Techniques Used

  • Power Query for cleaning, transformation, and feature engineering.
  • Star-schema modeling for clearer relationships and faster reporting.
  • DAX measures for fraud rate, cumulative trends, and high-risk period tracking.

Outcome

What the dashboard makes easier.

  • Spot risk concentrations by time and location.
  • Compare category-level fraud exposure.
  • Monitor evolving fraud behavior through interactive reporting.
