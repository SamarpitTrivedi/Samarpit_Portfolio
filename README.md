# Samarpit Portfolio

Welcome to my personal portfolio repository. This project showcases my work in data analysis, machine learning, and web development.

## Project Overview

This portfolio includes:

- **Web Interface**: Built using HTML, CSS, and JavaScript.
- **Resume Page**: An interactive resume highlighting my skills and experiences.
- **Certificates Page**: A collection of certificates from various courses and projects.
- **Project Showcases**: Demonstrations of data analysis and machine learning projects.

## Folder Structure

- `.vscode/`: Visual Studio Code settings.
- `certificates/`: Folder containing certificate images.
- `css/`: Stylesheets for the website.
- `font-awesome/`: Icons used in the project.
- `fonts/`: Custom fonts for the website.
- `img/`: Images used in the project.
- `js/`: JavaScript files for interactivity.
- `less/`: LESS files for styling.
- `presentation/`: Presentation materials related to the portfolio.
- `resume/`: Resume-related files.
- `LICENSE`: Project license file.
- `README.md`: Project documentation.
